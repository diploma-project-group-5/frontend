# web — веб-клієнт «Лад»

React SPA за специфікацією MVP «Лад» (v24, 03.11.2026): кабінети системного адміна й укладача
розкладу, публічні сторінки за QR (`/c#токен`, `/t#токен`) і аркуші для друку.

Віддається статикою через шлюз Traefik на `/`. Вхід — Keycloak за `/idp`, API — `/api/v1/*`
(усе одне походження, тож CORS не потрібен).

## Стек

| Що           | Вибір                                                  | Чому                                                                |
| ------------ | ------------------------------------------------------ | ------------------------------------------------------------------- |
| Збірка       | Vite + React 19 + TypeScript (strict)                  | статичний SPA, швидка збірка                                        |
| Маршрути     | React Router (data router, ліниві чанки)               | сторінки за QR не завантажують keycloak-js і код кабінету           |
| Дані сервера | TanStack Query                                         | кеш, опитування `GET /jobs/{id}`, `retry` лише для 5xx              |
| Вхід         | keycloak-js, Authorization Code + PKCE (S256)          | розділ 08; окремих `/login`, `/refresh`, `/me` немає                |
| Стилі        | CSS Modules + токени з прототипу, шрифт Onest у збірці | CSP `default-src 'self'`: жодних сторонніх шрифтів і CDN            |
| QR           | `qrcode.react` (SVG у браузері)                        | друк — HTML + print-CSS, без серверних PDF                          |
| Час          | date-fns + @date-fns/tz                                | «сьогодні», ISO-тиждень і +7 днів — у Europe/Kyiv, не зоні браузера |
| Тести        | Vitest + Testing Library                               |                                                                     |

## Запуск

Потрібен Node 24 (`.nvmrc`; мінімум 22.22).

```bash
nvm use
```

```bash
npm install
```

```bash
npm run dev
```

Dev-сервер на `http://localhost:5173` проксює `/api` і `/idp` на `DEV_PROXY_TARGET`
(за замовчуванням `http://localhost` — стенд `platform` у docker compose). Змінні — у `.env.example`.

Перевірки (те саме, що в CI):

```bash
npm run check
```

## Структура

```
src/
  api/        http-клієнт (problem+json → ApiError), ендпоінти сервісів, типи, опитування задач
  auth/       keycloak-js, AuthGate, перевірка ролей sysadmin / scheduler
  app/        маршрути
  layouts/    кабінет з меню
  lib/        час у Europe/Kyiv, токен QR
  pages/
    admin/      реєстрація закладу (тимчасовий пароль показується один раз), список закладів
    scheduler/  версії, побудова, сітка + навантаження укриття, публікація, QR
    public/     сторінки за QR — без акаунта
    print/      аркуші QR класів і вчителів (print-CSS)
  ui/         токени, базові компоненти
nginx/        конфіг віддачі статики з заголовками безпеки
```

## Що готово, а що ні

Готово (головний сценарій демо 13.11):

- вхід через Keycloak, розведення за роллю;
- адмін: `POST /schools` з одноразовим показом тимчасового пароля, `GET /schools`;
- укладач: `:build` → 202 → опитування `GET /jobs/{id}` (переживає оновлення сторінки), список
  версій зі станом «запланована / чинна / архівна», обчисленим з дати;
- сітка уроків по днях з форматом дня класу, `/load` (обидві умови для 1.2), підсумок;
- `:publish` з реквізитами наказу, `effective_from` ≥ +7 днів, окремий екран для `409 stale`,
  `warnings.lost_substitutions[]`;
- QR: список, перевипуск, аркуші для друку;
- сторінки `/c` і `/t`: два тижні, очно / дистанційно, «Заміна», банер, однаковий текст для 404.

Заглушки (дані для демо — із сід-файлу): профіль, дзвінки, класи, предмети, вчителі, план,
розклад тривог, журнал. Етап 2 (ручна правка, заміни, канікули, права вчителя) — не починали.

## Домовленості

- **Типи API** у `src/api/types.ts` написані вручну за специфікацією; поля, яких вона не фіксує,
  позначено `// припущення`. Коли `contracts` опублікує пакет з OpenAPI-типами — замінити реекспортом.
- Поля — `snake_case`, як в API; не перетворюємо їх у camelCase.
- Заклад береться з JWT — у шляхах його немає.
- Токен QR — лише у фрагменті URL і заголовку `X-Access-Token`, ніколи в query чи логах.
- На сторінках за QR не показуємо назву закладу, підписи вчителів на сторінці класу, місткість.

## Docker

```bash
docker build -t lad-web .
```

Образ на `nginx-unprivileged`, порт `8080`, `/healthz`. На `main` CI публікує
`ghcr.io/<org>/web:<sha>`; викатка — зміною тегу в репозиторії `platform`.
